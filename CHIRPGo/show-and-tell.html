AT878Sync

A native Android codeplug programmer for the AnyTone AT-878 — read, edit, and write channels and radio settings over a USB programming cable, no desktop required.

On-device only, no cloud Built for ham radio operators In active development
Early build, not yet released. Core read/write is working and confirmed on real hardware — this page tracks what's actually done, not a roadmap.

Programming an AnyTone AT-878 today means a Windows-only CPS app and a cable tethered to a desktop. AT878Sync (project name CHIRP-Go) puts that same job on your phone or tablet — plug in the same USB programming cable via OTG, and read or write the radio directly from Android. No manual codeplug data entry either: repeater data is meant to come from RepeaterBook once that integration lands.

Connect

Talks to the AT-878 over its own USB cable

Plug the radio in over OTG and AT878Sync finds it, requests USB permission, and opens a real connection using the radio's actual handshake protocol — confirmed on real hardware, reporting back the radio's own model/firmware string ("Connected: D878UV2V101").

Channels

Read, edit, and write your channel list

A filterable channel list (search by name or frequency) with an FM/DMR badge per row. Tap a channel to open a full tabbed editor — Basic, Digital, Analog, and Raw — covering name, frequency, offset, power, tone/CTCSS/DCS, DMR color code and timeslot, scan list, and every other documented field, laid out to match the official CPS's own groupings.

  • Edits are local until you explicitly write them back to the radio
  • A confirmation step always stands between an edit and a real write — never auto-push
  • Read/write confirmed working end-to-end on real hardware, including a name-only edit round-trip that left every other byte untouched
Frequency/offset writes are implemented and tested on the same read-modify-write path as name; some less-common per-channel fields are still read-only pending further protocol confirmation.
Radio Settings

General Settings, mapped tab by tab

The AT-878's radio-wide "Optional Setting" dialog — Work Mode, Power-on, Alert Tones, Display, GPS/Ranging, VFO Scan, Auto Repeater, Record, Volume/Audio, Vox/BT, STE, FM, Power Save, Key Function, Other, and Digital Func — reproduced as the same tabbed layout, with each field's real live value shown once confirmed against the radio's own protocol.

Several tabs — Digital Func, Record, and Volume/Audio — are fully mapped end to end; others are filled in incrementally as each field's byte offset is confirmed by capturing and diffing real traffic from the official desktop CPS.

Reading is live and working; writing General Settings back to the radio isn't built yet — this screen is read-only for now.
Safety

Built so a bad write can't brick your radio

Writes go one field at a time with each response verified before moving to the next, stop immediately at the first failure (reporting exactly what failed), and never touch the radio without an explicit confirmation dialog first. A session's edits stay in memory until you write them or explicitly exit — nothing is silently discarded on a dropped connection.

Design

A real Material 3 interface, not a debug tool

A dedicated color/type/spacing system, status pills for FM/DMR, bordered section cards, and a two-column layout on tablets — verified on both a phone and a tablet, not just a phone-shaped emulator.

About AT878Sync

AT878Sync requires an AnyTone AT-878 and its USB programming cable. It's not yet published — the AT-878 driver is being built out fully before any other radio is added, and before a public release.
